# Pure validator01: contract cho code-prep, chưa installer

08/11/2026. Hai API trong `packet_validator01.py`: `validate_packet(packet, artifact_bytes, trusted_review=...)` và `evaluate_compatibility(report, lock_bytes, target, expected_bindings=...)`. Chúng chỉ nhận objects/bytes, không filesystem, subprocess, normal-target startup, pip/network/Torch/GPU/model. Caller phải kiểm bounded regular files/no symlinks/live-before-after độc lập ở phase sau; pure validator không làm hoặc tự cấp quyền đó.

`trusted_review` bắt buộc đến từ reviewer ngoài packet: role (`ENGINEERING_FIXTURE` hoặc `REVIEWED_ACTUAL_FRESH_GPU_HOST`), parent_review_reference, bootstrap_approval_reference (approval riêng của actual creation, không giả cùng approval install), run_id, artifact_sha256 cho đủ11labels, producer_sha256 cho4future receipt producers và evaluator_packaging_version. Đây là trust input hợp tác, **không xác thực chữ ký, freshness hay thẩm quyền**. Bốn historical immutable pins vẫn baked trong source: bootstrap policy5a0845..., Linux lock60dad..., selected report92a2..., resolution32fe...; cold-bootstrap source037d... kiểm trong descriptor. Hash/provenance không được tự thay trong packet. Fresh cfg hash có thể giống CPU cfg nếu actual creation thật; source không dùng hash khác làm bằng chứng độ mới. Actual cfg.version phải bằng ABI fullversion; bootstrap result approval/cap30 phải đúng external review.

Future receipt envelope cho `fresh_empty_probe`, `startup_review`, `base_pip_review`, `target_compatibility` có exact keys: schema_version1, role `FRESH_GPU_HOST_<LABEL_UPPER>`, status `REVIEWED_PASS`, run_id, approval_reference, source_sha256, bindings, facts. Bindings exact descriptor_sha256/bootstrap_result_sha256/cfg_sha256/abi_sha256 (ABI canonical JSON sortkeys,separators(',',':')). Đây là **hợp đồng đầu vào đề xuất**, chưa có actual producers/fresh receipts và chưa chứng minh chúng trên GPU host.

- Normal-empty facts: actual normal prefix/executable/base_prefix, no distributions/pip/numpy/torch specs, user_site_enabled false, purelib_empty true và cfg/ABI SHA.
- Startup facts: base_approved, target_approved, unknown_hooks_absent, cuda_hidden, record_bindings_accepted phải true; exact base/target rawfacts/reviewmanifest SHAs. Đây chỉ là consistency của reviewed inputs; hook body/syscall/security inspection vẫn ở producer/reviewer riêng. Old CPU receipt role không hợp lệ.
- Basepip facts: reviewed26.2.2, actual origin+SHA, Python isolation, sole PIP_CONFIG_FILE=/dev/null, empty file-effective entries, strict flat hoặc nested config dict. Unknown pip version/config STOP, không downgrade/install.
- Compatibility facts: exact11marker_environment strings, tags (actual uncompressed supported triple list), requested_root_extras=[], bindings đến descriptor/cfg/startup/basepip/emptyprobe/lock/report/ABI. Dùng public packaging tại evaluator, version phải khớp external review. Pure API không hash/import-origin-attest chính dependency đang chạy; outer reviewed source/tool inventory còn bắt buộc. Không lấy local `default_environment()` hay chạy target.

Full44 wheel/name/version/officialURL/hash/tag checks, Python specifier và từng Requires-Dist dùng public packaging. Active missing/conflict/URL/extras hoặc marker grammar lạ failclosed. Inactive extra clauses được ghi nguyên raw/index/reason; không auto resolve/adopt extras. Stored report đang có478rawrows (41RequiresPython/3unspecified); target mới phải được đo và review, không lấy report CPU làm fresh target. Test dùng in-memory ENGINEERING fixture và union of stored wheel tags chỉ để test semantics, **không phải actual tag receipt hoặc ABI compatibility evidence**.

Kết quả chỉ byte/receipt consistency; execution_authorized luôn false và runtime_or_install_verified false. Actual-role output vẫn yêu cầu current-host recheck, không install-ready/GPU-ready. Old CPU v3/bootstrap/source/report/lock không sửa.

Tests là stdlib unittest+public packaging, command local .venv; cumulative toàn bộ mock attempts≤30s, snapshot/log/failures giữ riêng. Không test bằng target Python/pip/Torch/network/remote. Chưa có actual cold bootstrap, normal-empty/base+target startup/current basepip/targettags provenance trên GPU host, nên chưa có runnable install packet.
